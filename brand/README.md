# Brand files

Replace these two pictures with your own, keep the same file names, and push.
The build makes every app icon, the TV banner, the start-screen logo and the
in-app logo from them.

| File | What it is | Size |
|---|---|---|
| `icon.png` | The symbol only (no text). Transparent background, square. Used for the launcher icon, TV banner, start screen and intro. | 1024 x 1024 px PNG |
| `logo.png` | Symbol + name, wide. Transparent background. Shown at the top-left of the home screen. | about 1100 x 256 px PNG (any width, 256 px high) |

Name, package name and website address: `brand.txt`.
